# Icons

The Wallpaper Mage logo (a wizard hat over a swirl around a star) in the shapes and sizes apps, sites and stores ask
for. Every file is generated by `scripts/make-icons.py` from `source/artwork.png`; edit the artwork, not the outputs.

| Folder | What it is |
| --- | --- |
| `transparent/` | The logo alone on a transparent background. Best on dark backgrounds (its yellow fades on white). |
| `white/`, `black/` | One-colour silhouettes of the logo, transparent background. |
| `square/` | The logo on its dark background, full-bleed square. |
| `rounded/` | The same as a rounded square (superellipse) with transparent corners. |
| `circle/` | The same as a circle, for avatars. |
| `macos/` | A macOS-style icon: the rounded square on Apple's icon grid (824 px in 1024), with its drop shadow. |
| `wallpaper-mage.ico` | Favicon / Windows icon from `rounded/`, 16–256 px. |
| `source/` | `artwork.png` (the master) and `logo.png` (the logo cut out of it at full resolution). |

Each folder holds 16, 24, 32, 48, 64, 96, 128, 180, 192, 256, 512 and 1024 px PNGs named
`wallpaper-mage-<folder>-<size>.png`.

## App and menu bar icons

The script also builds the icons the apps ship with, in `Resources/`:

- `AppIcon.icon`: an Icon Composer document (a dark fill and the logo layer). macOS 26 draws the shape, edge and
  shadow itself; it can be opened and adjusted in Icon Composer.
- `Assets.car`: that document compiled by Xcode's `actool` (`CFBundleIconName` = `AppIcon`).
- `AppIcon.icns`: the `macos/` PNGs as the flat fallback (`CFBundleIconFile` = `AppIcon`).
- `MenuBarIcon.png`, `MenuBarIcon@2x.png`: the background service's menu bar item, the logo's shape as an 18 pt
  template image (the menu bar tints it).

`build.sh` copies `Assets.car` and `AppIcon.icns` into the Settings app and the menu bar icon into the service, which
has no app icon of its own: it runs as a menu bar item only.

## Regenerating

```sh
python3 -m venv /tmp/icons-venv && /tmp/icons-venv/bin/pip install numpy pillow scipy
/tmp/icons-venv/bin/python scripts/make-icons.py
```

It needs Xcode (for `actool`) to rebuild `Assets.car`; without it everything else is still rebuilt.
